## Project Description
This project uses Machine Learning and Natural Language Processing (NLP) to predict a movie genre from its plot description.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression
- Matplotlib

## Project Workflow
1. Create a movie plot dataset.
2. Convert text descriptions into numerical features using TF-IDF.
3. Train a Logistic Regression model.
4. Evaluate model performance.
5. Predict the genre of a new movie plot.
6. Visualize the distribution of movie genres.

## Files Included
- movie_genres.csv: Dataset
- movie_genre_model.pkl: Trained model
- genre_distribution.png: Genre distribution graph
- model_results.txt: Model evaluation results
- README.md: Project documentation

## Limitations
This is a beginner prototype using a small sample dataset. Its accuracy may not represent real-world performance.
